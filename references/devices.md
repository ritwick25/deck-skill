# Device registry

The visual mechanisms the archetype cards cite as `dvNN` (taxonomy v1). A device is how a slide argues: the archetype is the job, the device is the drawing.

| Id | Device | Mechanism |
|---|---|---|
| dv01 | Corner numeral disc | A quarter disc bleeds off one corner and holds the section numeral, so position reads before the title. Each divider reuses the frame. |
| dv02 | Ghost numeral | An oversized pale numeral or word sits beside or behind a short title as a watermark position marker. |
| dv03 | Lit tile in a reprinted grid | The contents grid returns at each boundary with the current tile saturated and the rest greyed, so the agenda doubles as a progress meter. |
| dv04 | Bar-built pictogram | An emblem drawn only from the deck's own flat bars stands in for an icon on a divider or card. |
| dv05 | Medallion straddling an edge | A roundel, numeral, letter or portrait sits across the edge of a band or card, half on each ground, binding the two and indexing peers. |
| dv06 | Tab header on a column | A filled tab or bar caps a column or lane and names it, over an outlined or tinted body. |
| dv07 | Chevron stage header | A row of chevrons, or numbered tabs joined by small chevrons, names the stages and heads the column of content beneath each. |
| dv08 | Foundation band | A full-width band under a row of columns or a chain names what all of them rest on or share. |
| dv09 | Dashed trust boundary | A dashed frame encloses the owned components while an outside zone sits beyond it, so every crossing arrow reads as a decision. |
| dv10 | Label chip on a boundary | A pill sits on a dashed divider or frame edge and names the line it marks. |
| dv11 | Connector key | A small key decodes line styles, solid, dashed or coloured, so each arrow type carries one meaning. |
| dv12 | Gate under each stage | A chip, disc or check under every step names the control that fires there. |
| dv13 | Question ladder | A trigger card heads numbered yes or no rungs, each rung ending in the action it routes to. |
| dv14 | Exception return loop | A dashed path below the main row carries the failure case back into the flow, struck through when the loop never closes. |
| dv15 | Fan-out spine | One spine splits into parallel lanes through a shared band and rejoins into one output. |
| dv16 | Serpentine track | One line snakes across rows threading numbered discs or cards, keeping a long sequence in reading order. |
| dv17 | Roundel spine | Icon or numbered discs strung on one line, each heading the card or list that hangs beneath it. |
| dv18 | Bracket gather | A brace or bracket gathers several items into one group that then feeds the next element. |
| dv19 | Petal or wedge hub | Petals, wedges or lobes radiate from a core disc, each tied to its own detail card. |
| dv20 | Quartered hub with expanded tile | Four tiles meet at a split disc, and one tile opens into a detail panel while the others stay muted. |
| dv21 | Convergence disc | Arrows from several cards or groups converge on one disc that stands for the shared result, then read out to outcomes. |
| dv22 | Milestone diamond on a gate line | A dashed vertical crosses a period grid and lands on a labelled diamond marking a gate. |
| dv23 | Phase-banded bar rows | Full-width tinted bands group the task bars on a time grid, so phases read as blocks before bars. |
| dv24 | Milestone rail | A horizontal rail of dated markers runs under or over phase cards, so each phase lands on a date. |
| dv25 | Rising curve with riders | A rising line or area under period headers carries vignettes, markers or figures at the point each one arrives. |
| dv26 | People to agents shift | Person glyphs thin out across period columns while agent nodes grow denser, so the change in who does the work reads without words. |
| dv27 | Tint-stepped progression | Fills step from pale to strong across columns, rungs or cards, so order or readiness reads before the text. |
| dv28 | Wedge or bridge between states | A solid wedge, block arrow or drawn bridge spans the gap between a current and a target panel, so the shift is one mark. |
| dv29 | Two-state card | Each card splits into a before half and an after half under one dimension label, repeated across the set. |
| dv30 | Struck before value | A struck-through old figure or step sits beside its replacement, so the change reads as an edit. |
| dv31 | Argument rail | A narrow full-height rail, or a row of three, restates the slide as problem, why it matters, approach and the decision it supports. |
| dv32 | Owner strip | Labelled cells name the owner, gate, phase and dependencies of what the slide describes, so accountability reads as data. |
| dv33 | Figure rail | A solid side column stacks the outcome figures that close a case or a page, read last. |
| dv34 | Stat band | A band or row of three to six large figures with short labels anchors the claims above or below it. |
| dv35 | Sourced figure | Each figure carries a short basis or source line beneath it, so the number travels with its provenance. |
| dv36 | Equation band | A spelled-out sum heads the slide and each term drops into its own driver card beneath. |
| dv37 | Waterfall bars | Stepped bars decompose a total into signed contributions, from a base to the result. |
| dv38 | Share ring | A donut or partial ring around a central glyph or figure sizes one share or split. |
| dv39 | Small multiples | A grid of identically scaled small charts isolates the one series that behaves differently. |
| dv40 | Partial-fill score marks | Partially filled circles or dot meters grade each cell, so a pattern reads across rows without numerals. |
| dv41 | Heat-shaded cells | Cell fills step through one hue by value, so strong and weak rows read before any word. |
| dv42 | Numbered key decode | Small numbered tags on the visual are decoded in a side key or in matching numbered tiles elsewhere on the slide. |
| dv43 | Leader-lined callouts | Outlined callouts on leader lines point at the exact part of an image, plan or map each note concerns. |
| dv44 | Pinned or shaded map | A flat map carries reach or rollout as pins, shaded regions or region callouts. |
| dv45 | Scope beam | A widening wedge from a lens covers the in-scope list while a pale narrowing wedge covers what is out. |
| dv46 | Pyramid keyed to rows | A tiered pyramid whose levels point across to rows of cadence, attendees or decisions. |
| dv47 | Waterline split | A horizontal waterline separates the visible symptoms above from the hidden gaps below. |
| dv48 | Venn overlap | Two or three overlapping circles hold what each side brings, with the shared part named in the overlap. |
| dv49 | Dot count grid | A grid of dots, some filled or ringed, counts hits and misses so a ratio reads at a glance. |
| dv50 | Payload well | A monospace panel holds the literal record or payload at a hop, often paired input to output. |
| dv51 | Curved hand-off | A curved arrow between persona glyphs carries the work from one actor to the next on a time axis. |
| dv52 | Mini device per column | Each peer column draws its own small diagram, so one slide carries several mechanisms side by side. |
| dv53 | Portrait disc with name and role | A circular portrait over a bold name and a lighter role line, repeated in a row or grid. |
| dv54 | Edge-cropped disc | An oversized disc cropped by the slide edge carries a group label or frames one closing line. |
| dv55 | Full-height quotation panel | A flat panel the full height of the slide holds one attributed quotation beside plain contact detail. |
| dv56 | Device frame with demo pill | A browser or laptop frame straddles a full-width band, with a pill on the band marking a live demo hand-off. |
| dv57 | Status marks | Tick, cross or traffic-light marks on items carry their state with an icon and a label, never by colour alone. |
| dv58 | Hairline-ruled numbered rows | Bold numerals lead plain labels on rows separated by hairlines on open ground. |
| dv59 | A4 portrait one-pager | A portrait page stacks an objective band, an annotated hero image, method strips and outcome figures, so one printed page argues alone. |
