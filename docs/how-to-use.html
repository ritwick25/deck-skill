Five ways to use /deck

Type /deck anywhere in a prompt to Claude Code. The word after it picks what happens.

1

Build a whole deck

/deck new

Restates the job and waits for a yes, asks for the client's colors, logo and font, drafts a one-line-per-slide outline in the RFP's own section order, then builds, checks and reads every slide.

/deck new RFP response for a specialty pharma field team. RFP at ./rfp.pdf, about 25 slides, scored on approach, architecture, team and commercials.

2

Add or rebuild one slide

/deck slide

Picks the right slide type for the point being made, builds it into the deck, checks it and reads it beside its neighbors.

/deck slide a roadmap from kickoff on 2 Nov to full rollout on 22 Jan, with three gates, --deck ./build.py

3

Draw a technical diagram

/deck diagram

Enterprise AWS or Azure notation with official icons, or the house style. Reference and deployment views, CI/CD, MLOps, data lineage, events, sequence, data flow with threat controls, C4, DR and landing zone.

/deck diagram azure deployment for the agent platform: hub and spoke, private endpoints, Container Apps, Azure OpenAI behind a firewall

4

Chart your own numbers

/deck chart

A native PowerPoint chart from the data supplied, labeled with its basis. It asks for the source and never invents a figure.

/deck chart first-year price as a waterfall: build $180K, then $24K a month for 12 months

5

Review or fix a deck

/deck review · /deck edit

Review runs 27 automated checks (8pt floor, overflow, overlap, loose arrows, banned words, contrast, footers, word budgets, repeated layouts), reads every slide and reports. Edit changes only what is pointed at, and a deletion is swept across the whole deck.

/deck review ./draft.pptx

/deck edit ./draft.pptx remove the confidentiality footer from every slide

One session, one skill

Once /deck is loaded, later edits in the same session go through it without typing it again. After a long session is compacted, type it once more.

Client brand first

A client deck with no brand given starts by asking for colors (hex codes or a website), the logo and the font. Say "house theme" to skip.

The showcase
